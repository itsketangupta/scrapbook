# Little Things — Personal Scrapbook

A private-feeling, browser-only scrapbook for photos and daily notes.

## Run locally

Open `index.html` in a browser. No server, build step, or dependencies are required.

## Deploy to Vercel

1. Create a new GitHub repository.
2. Push this folder to that repository.
3. Import the repository in Vercel.
4. Leave the framework preset as **Other** and the build command empty.
5. Deploy.

The app stores memories in the visitor's browser using IndexedDB. Images and notes are not uploaded to Vercel. Use the app's **Export** button to create backups.
